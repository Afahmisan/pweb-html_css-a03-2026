Tugas Praktikum Pemrograman Web Modul 1 2026. Proyek ini adalah sebuah website portofolio dan *Creative CV* mandiri yang dibangun dari awal (*native from scratch*) menggunakan HTML dan CSS murni tanpa *framework* tambahan.

## Akses
Akses website secara langsung melalui tautan berikut:
**[https://kelompokprabowo.netlify.app](https://kelompokprabowo.netlify.app)**

## Fitur 
- **Native HTML & CSS:** Dibangun sepenuhnya tanpa *framework* (seperti Tailwind atau Bootstrap).
- **Multi-Page Architecture:** Terdiri dari 4 halaman utama yang saling terhubung (`index.html`, `cv.html`, `mbg.html`, `kopdes.html`).
- **Responsive Design:** Tata letak dinamis dan optimal untuk tampilan layar PC, Tablet, maupun *Smartphone*.
- **Modern Layouting:** Mengimplementasikan CSS Flexbox, CSS Grid, *Positioning*, dan *Pseudo-classes* secara ekstensif untuk UI/UX yang interaktif.
